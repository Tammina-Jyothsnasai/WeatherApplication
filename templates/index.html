About WeatherApplication

Back to Dashboard

WeatherApplication is a modern weather intelligence platform delivering real-time meteorological conditions, interactive 24-hour hourly trend analytics, five-day weather forecasts, air quality index monitoring, solar arc tracking, and persistent favourite cities backed by MySQL and Flask REST APIs.

Key Features

  • Current weather queries across global cities with resilient fuzzy resolution.
  • Real-time canvas weather animation effects (falling rain, snow, drifting clouds, twinkling night stars).
  • 24-Hour hourly temperature spline chart with interactive hover metrics.
  • Sun Position Solar Arc visualizer tracking sunrise, sunset, and active daylight.
  • Air Quality Index (AQI) monitoring with PM2.5, PM10, O3, NO2 metrics and health guidance.
  • Wind Direction 360° Compass with rotating needle and gust tracking.
  • Interactive Leaflet Weather Radar Map with live precipitation overlay.
  • Seamless °C and °F temperature unit toggling without redundant network calls.
  • Favourite cities persistence via MySQL REST APIs with Add, Edit Nickname, and Delete operations.

How It Works & Stack

  • Frontend: HTML5, Responsive CSS3 Grid/Flexbox, ES6+ JavaScript, Leaflet.js, Canvas Animations, Bootstrap 5.3, Bootstrap Icons.
  • Backend: Python 3.13, Flask REST API endpoints (`/api/weather/current`, `/api/weather/forecast`, `/api/favorites`).
  • Database: MySQL relational database (`favorites` table) with parameterized SQL safety.
  • API Security: OpenWeather API keys remain secured on the server side and are never exposed in frontend files.
